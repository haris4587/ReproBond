# Synthetic calibration experiment: pendulum period

This is an educational protocol fixture, not a published scientific finding.
Hypothesis: a pendulum of length 1.00 metre has a period between 1.90 and 2.10 seconds.
Protocol: use a 1.00 metre string, small angle (5 degrees), time ten full oscillations per trial, three trials.
Report length, release angle, timing method, each measured duration, mean period, deviations, result and limitations.
Allow timing by a handheld stopwatch and length uncertainty up to 1 cm. Disallow changing string length or using a large release angle.
Original fixture measurements: 20.0, 20.1, 19.9 seconds for ten oscillations; mean period 2.00 seconds.
No inference about real-world replication should be drawn from these synthetic values.
